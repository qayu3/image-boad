保存先の設定

GitHub のリポジトリにボードを保存すると、そのリポジトリに書き込める人同士で同じボードを編集できます。

トークンはこのブラウザの中にだけ保存されます。リポジトリの持ち主は Fine-grained token（このリポジトリの Contents: Read and write）、共同編集者は classic token（public_repo）を使ってください。空欄の場合は、公開リポジトリのボードを見るだけになります。
